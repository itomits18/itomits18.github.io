### Participant Routes

---

### **Base URL**

`http:localhost:8080/api/participants`

---

### **Endpoints**

---

### 1. **Get All**

**GET** `/?order_by=created_at&sort_by=asc&limit=2&page=1`

This endpoint allows users to get all of their data.

**Response Example (Success)**:

```json
{
    "code": 200,
    "message": " ",
    "data": {
        "id": 7,
        "name": "John",
        "email": "john@gmail.com"
    }
}
```
